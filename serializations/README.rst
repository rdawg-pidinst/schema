Serializations
==============

This directory contains definitions for supported serializations for
the PIDINST schema.

Note that the PIDINST schema by itself defines the properties to
represent instrument descriptions and the semantics of these
properties.  It is technology agnostic and not limited to one
particular serialization format.  However, the RDA Persistent
Identification of Instruments WG provides formal definitions for a
selection of serialization formats.

The list of supported serialization formats includes:

- XML: XML Schema Definition files are provided in
  `pidinst-schema-<v>.xsd`, where the `<v>` stands for the PIDINST
  schema version.
